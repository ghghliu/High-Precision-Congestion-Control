# 400G PFC vs DCQCN microbenchmarks

Baseline suite for exposing:

1. **PFC head-of-line (HoL) blocking** — pause on a shared fabric hop stalls an uncongested victim.
2. **DCQCN small-flow slow recovery / under-utilization** — short flows finish while rate is still climbing after CNP cuts.

## How to run

```bash
cd simulation
# one-time: python2 + ./waf configure --enable-modules=... && ./waf build
bash scripts/run_bench_p0.sh
```

Or individually (config is generated by `run.py`, no hand-written config needed):

```bash
python2 run.py --cc pfc   --topo bench_hol --trace bench_hol_flow --bw 400 --stop 2.05 --enable_tr 1 --trace_nodes trace_hol
python2 run.py --cc dcqcn --topo bench_hol --trace bench_hol_flow --bw 400 --stop 2.05 --enable_tr 1 --trace_nodes trace_hol
python2 run.py --cc pfc   --topo bench_sf  --trace bench_sf_flow  --bw 400 --stop 2.05 --enable_tr 1 --trace_nodes trace_sf
python2 run.py --cc dcqcn --topo bench_sf  --trace bench_sf_flow  --bw 400 --stop 2.05 --enable_tr 1 --trace_nodes trace_sf
python3 ../analysis/analyze_bench.py --mix mix
```

`--cc pfc` sets `ENABLE_QCN 0` (no ECN/CNP) while keeping dynamic PFC thresholds.

## Topologies (all links 400Gbps, 1000ns)

### B1 HoL — `mix/bench_hol.txt`

```
hosts 0,1,2 -- Leaf0(5) -- Leaf1(6) -- hosts 3 (victim dst), 4 (incast dst)
```

Flows (`bench_hol_flow.txt`):

| Flow | Path | Role |
|------|------|------|
| 0→3 :100 | crosses 5–6 | victim (50MB) |
| 0,1,2→4 | 3:1 incast on 6→4, shares 5–6 | congestors (200MB) |

Expected: under PFC-only, ingress buildup at Leaf1 pauses the 5–6 link and inflates victim FCT/slowdown; DCQCN should trigger fewer/shorter pauses via ECN rate control.

### B2 Small-flow — `mix/bench_sf.txt`

Star: hosts 0–3 attached to switch 4.

Flows (`bench_sf_flow.txt`):

| Flow | Size | Start | Role |
|------|------|-------|------|
| 0→1 | 200MB | 2.0s | elephant |
| 2→1, 3→1 | 100KB ×4 | 2.001s | late short flows sharing downlink to 1 |

Expected: DCQCN AI/HAI recovery after CNP is slow vs flow lifetime → high small-flow slowdown / poor short-term utilization vs ideal standalone FCT.

## Outputs

- `mix/fct_bench_*_{pfc,dcqcn}.txt` — FCT rows: `sip dip sport dport size start_ns fct_ns standalone_ns`
- `mix/pfc_bench_*_{pfc,dcqcn}.txt` — PFC events: `t_ns node node_type ifindex type(1=pause,0=resume)`
- `mix/mix_bench_*.tr` — packet-level trace when `--enable_tr 1`
